# PixelForge Studio v1.2.0

## Brush Studio
- Кисть и ластик с размером 1–16 px.
- Квадратная и круглая формы.
- Зеркальное рисование по горизонтали и вертикали.
- Размер кисти применяется к линиям, прямоугольникам и эллипсам.
- `Alt` + клик по холсту — временная пипетка.

## Совместимость
- Формат проектов остаётся v5; существующие проекты открываются без миграции.
- Сохранены слои, клипы, кадры, таймлайн и экспорт.
