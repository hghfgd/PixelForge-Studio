# PixelForge Studio v1.4.0 — Animation Assist

Тёмный пиксельный редактор для создания игровых спрайтов и покадровой анимации.

## Возможности версии 1.4.0

- Onion Skin: предыдущий и следующий кадры видны разными полупрозрачными цветами.
- Pivot Point и события (`footstep`, `hit` и любые пользовательские метки) сохраняются для каждого кадра.
- Массовый выбор кадров: `Ctrl`/`Cmd` + клик, диапазон через `Shift` + клик; групповое дублирование, удаление и изменение длительности.
- Отдельные слои-части персонажа через кнопку `Part` (Head, Body, Arm, Weapon и т. п.).
- Замена цвета по всему проекту, включая все клипы и слои.
- Загрузка референса движения в инспектор; референс не попадает в экспорт спрайта.
- Автосохранение в локальное хранилище приложения и восстановление при следующем запуске.
- Эвристическая проверка пустых кадров, касания краёв холста, выхода Pivot за границы и больших скачков центра спрайта.
- Экспорт данных всех клипов и отдельных GIF для каждого клипа; JSON содержит FPS, loop, длительности, pivot, события, слои и пиксели.
- Настройка фона предпросмотра (шахматка/тёмный/светлый).
- Кэширование миниатюр таймлайна и виртуализация длинных таймлайнов (окно из 60 карточек при более чем 80 кадрах).

## Управление

- `B` — карандаш, `E` — ластик, `G` — заливка, `I` — пипетка.
- `Ctrl+Z` / `Ctrl+Y` — Undo / Redo.
- `Ctrl` + клик по карточкам — множественный выбор; `Shift` + клик — диапазон.
- `←` / `→` — соседний кадр; `Space` — воспроизведение.
- Перетаскивание карточки — изменение порядка кадра.

## Установка и запуск для разработчика

Требуется Windows 10/11 x64. Node.js нужен только для сборки/разработки, не для конечного пользователя.

```bash
npm install
npm start
```

## Сборка автономного Windows Setup.exe

На Windows-машине разработчика:

```bat
BUILD_INSTALLER.bat
```

Или загрузить проект в GitHub и запустить workflow **Build Windows installer** через Actions. Готовый `PixelForge Studio Setup.exe` появится в артефактах workflow. В установленном приложении Node.js не требуется: Electron включает нужную среду выполнения.

## Проверки

```bash
npm run test:all
```

Проверки выполняются на модели данных и обработчиках приложения. Они не заменяют полноценный визуальный тест на Windows.

## Формат проекта

Версия формата проекта: 5. Старые проекты v2–v4 читаются с миграцией к текущей структуре. Для каждого клипа хранятся FPS, loop и список кадров. Кадр хранит длительность, pivot, событие и пиксельные cels всех общих слоёв.

## Примечания

- Проверка анимации является эвристической подсказкой, а не автоматической оценкой качества движения.
- Пресеты Generic JSON, Godot, Unity и GameMaker формируют переносимый JSON-манифест с данными клипов и слоёв. Для прямого импорта в конкретный игровой движок потребуются отдельные импортёры/адаптеры.
- Референс загружается для визуального сравнения и не встраивается в проектный файл.


## v1.0.0 — Easy Workflow
- Сворачиваемые панели инспектора; состояние каждой панели сохраняется локально.
- Быстрое создание стандартных клипов Idle, Walk, Run, Jump, Attack и Death с подходящим FPS и настройкой Loop.
- Кнопка Fit и клавиша F подгоняют холст под доступную область.
- Справочник горячих клавиш открывается кнопкой ? или клавишей ?.
- Ctrl+S вызывает сохранение проекта.


## v1.0.0 — Рабочие пространства
- Добавлены режимы «Рисование», «Анимация», «Экспорт» и «Все инструменты».
- Панели автоматически скрываются по назначению, не удаляя функции приложения.
- Последний выбранный режим сохраняется локально.
- В режиме рисования таймлайн скрывается для увеличения рабочей области; в режиме экспорта скрывается панель инструментов.


## v1.1.0 — комфорт управления холстом
- Масштабирование колёсиком мыши с привязкой к позиции курсора.
- Перемещение холста средней кнопкой мыши или Space + перетаскивание.
- Горячие клавиши `+` и `-` для изменения масштаба.
- Ограничение масштаба увеличено до 4800%.


## v1.2.0 — Brush Studio
- Размер кисти от 1 до 16 пикселей для карандаша и ластика.
- Квадратная и круглая формы кисти.
- Горизонтальное и вертикальное зеркальное рисование (можно включить одновременно).
- Размер и форма кисти также применяются к инструментам «Линия», «Прямоугольник» и «Эллипс».
- Удерживайте `Alt` во время нажатия на холст, чтобы временно взять цвет пипеткой, не переключая инструмент.


## Новое в v1.4.0 — Animation Assist
- В раскрывающемся блоке ленты анимации доступны команды копирования активного слоя из соседнего кадра.
- «Промежуточные кадры…» создаёт 1–8 кадров плавного перехода между текущим и следующим кадром. Промежуточные изображения рассчитываются отдельно для каждого слоя с интерполяцией RGBA; это не автоматическая анимация движения конечностей.
- Луковая кожа позволяет видеть до четырёх соседних кадров с регулируемой прозрачностью.
