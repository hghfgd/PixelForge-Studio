# PixelForge Studio v1.4.0 — Animation Assist

## Меньше рутины при создании анимаций
- Промежуточные кадры: генерация 1–8 кадров между текущим и следующим кадром с интерполяцией цвета и прозрачности каждого пикселя отдельно в каждом слое. Это режим плавного перехода/растворения, а не автоматическое распознавание поз и суставов персонажа.
- Копирование содержимого активного слоя из предыдущего или следующего кадра — удобно переносить неизменные части персонажа между позами.
- Расширенная луковая кожа: просмотр до четырёх кадров до и после текущего с настраиваемой прозрачностью.
- Существующий формат проекта v5 сохранён.
