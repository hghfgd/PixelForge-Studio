# PixelForge Studio v1.3.0 — Animation Flow

## Упрощение анимации
- Основные операции с клипами и кадрами вынесены в одну компактную панель.
- Часто используемые команды всегда на виду: создать клип по шаблону, воспроизвести, добавить пустой кадр, скопировать текущий кадр, удалить кадр.
- Редкие настройки (движок экспорта, зацикливание, длительность, применение FPS и пакетные операции) скрыты в раскрывающемся блоке.
- Уменьшены миниатюры кадров, чтобы на экране помещалось больше кадров.
- Основные подписи ленты анимации переведены на русский.

Формат проекта не менялся (version 5).
